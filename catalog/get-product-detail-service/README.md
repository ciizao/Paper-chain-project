# Get Detail

## 🛠️ Tech Stack
- **PHP** 🐘 (Core backend language)
- **Laravel/Lumen** 🌍 (Lightweight framework for microservices)
- **MySQL** 🗄️ (Database for product storage)
- **Docker** 🐳 (Containerized deployment)
- **AWS EC2 & RDS** ☁️ (Cloud hosting)

## 🔧 Installation & Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/ciizao/Paper-chain-project.git
   cd product-microservice
   ```
2. Install dependencies:
   ```bash
   composer install
   ```
3. Set up environment variables:
   ```bash
   cp .env.example .env
   ```
4. Start the server:
   ```bash
   php -S localhost:8000 -t public
   ```
